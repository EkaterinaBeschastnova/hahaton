# Мой дом — frontend v2

В этой версии дом является единственной точкой привязки данных.

## Что изменено

- больше нет параллельных `demo.ts`, `myAddedHouses` и случайных ID;
- пользователь хранит только связь с `house.id`;
- события, заявки, счётчики и ремонты всегда имеют `buildingId`;
- экран дома никогда не подставляет другой адрес, если ID не найден;
- состояние дома не хранится строкой `statusText`, а вычисляется функцией
  `src/domain/houseState.ts`;
- если у дома нет причин для внимания, статус на карточке не показывается;
- при недоступном backend Mini App использует ту же структуру данных из
  `src/data/housesDatabase.ts` как демо-fallback;
- при доступном backend источником истины становится `/api/houses/*`.

## Проверка

```powershell
npm run typecheck
npm run dev
```

Backend должен быть доступен по `VITE_API_URL` или по умолчанию
`http://localhost:8000`.
